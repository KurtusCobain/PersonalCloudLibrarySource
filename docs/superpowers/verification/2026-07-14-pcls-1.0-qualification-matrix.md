# PCLS 1.0 qualification matrix - 2026-07-14

## Release decision

**Blocked.** The code-level and disposable-filesystem qualification passed. The supplied Playnite 10.56 installation and official `Toolbox.exe` removed the host-availability prerequisites, and an isolated Desktop/Fullscreen smoke run passed the setup, import, install-state, branding, and recent-activity checks described below. The final official Toolbox rerun packed successfully but could not reproduce addon verification because its HTTP checks could not reach the GitHub/raw URLs. An rclone executable, validated removable/mapped/UNC targets, historical installed profiles, multi-DPI evidence, and the remaining destructive/error-path UI cases are also unavailable or unexecuted. PCLS must remain at the pre-release version `0.3.2`; this document does not authorize a 1.0 identity, release publication, or PR merge. Task 17 must not begin until this Task 16 matrix has zero Blocked and zero Failed rows.

No external software was installed or downloaded. Qualification used an isolated portable copy under the Codex visualization workspace, a disposable Playnite profile, two text-only fixture games, and a disposable cache. The live ROMcade Playnite profile, library, settings, cache, and configured rclone remote were not mutated. The rclone inventory records availability/count only and intentionally omits remote names and configuration contents.
