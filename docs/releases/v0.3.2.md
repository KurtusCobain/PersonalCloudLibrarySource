# Personal Cloud Library Source v0.3.2

**Playnite library extension — public update from v0.2.0**

PCLS catalogs games you supply and control on local storage, external drives, NAS shares, and separately configured rclone remotes. Import a catalog, select the games to cache, and use Playnite's standard install, play and uninstall actions. PCLS does **not** supply games, accounts, cloud storage, ROMs, emulators or streaming.

## What's new

- **Guided setup and preview.** Bounded, cancellable read-only previews show candidate titles, skipped items and warnings before importing. Local/NAS catalog generation no longer blocks Playnite's setup window.
- **Cache-first on-demand transfers.** Copy selected local or rclone content into an explicitly configured local cache, with a queue, cancellation, retry, progress and a Desktop dashboard.
- **Safer filesystem operations.** New installs stay inside the chosen cache, existing destinations aren't silently adopted or overwritten, and linked/unsafe paths are rejected. Source content and cloud files aren't deleted by cache operations.
- **Windows stability.** Improved asynchronous install completion and UI-thread signaling, Windows ownership-receipt path handling, cancellation cleanup (including rclone temporary sidecars) and package validation.
- **Improved Playnite integration.** Dark-theme Details readability, source-health diagnostics, accurate live dashboard state, and standard game actions in Desktop and Fullscreen.
- **Compatibility.** v0.2.0 settings and game identities are migrated in place. The former default rclone timeout of 30 seconds becomes 90 seconds; custom values remain unchanged.

## Upgrade and safety notes

- **Back up your Playnite configuration and PCLS settings before updating.** Verify the source and cache paths in Desktop settings before updating your library.
- New installs targeting paths **outside** the configured cache are refused. Existing external content is not moved or deleted automatically.
- Recursive directory cache uninstall remains **disabled** pending additional safety qualification. File-only cache uninstall is available subject to policy checks.
- PCLS keeps original source/remote content separate from the cache. Do not use any personal cloud account or library as a test fixture.
- There is no dedicated setup wizard/dashboard in Playnite Fullscreen; configure sources in Desktop first.
- The cached-size display for items sharing a cache directory can overstate a single game's size. This is a presentation limitation, not a measured transfer size.
- Actual third-party cloud-provider and NAS scenarios may depend on credentials, network access, mapping and permissions; only a disposable local-only rclone backend was exercised during the Windows acceptance run.
